## Known limitations

- Remarks are short (median 3 words) and are mostly satisfaction feedback, so text alone carries a weak category signal; ML results must be read with that in mind.
- No priority labels exist → priority is rule-based (see `docs/PRIORITY_RULES.md`).
- No customer identifiers; every `Order_id` is unique, so repeat contact is detected from text cues ("already contacted", "three times").
- City / product / price are ~20% filled → charts show coverage.
- Only one month of data (August 2023).
